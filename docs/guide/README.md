# คู่มือสอน: สร้างระบบประเมินบุคลากร จาก 0% ถึง 100%

> คู่มือสำหรับครูและนักเรียน ปวช. ที่ซ้อมแข่งทักษะ **ข้อ 57 การพัฒนาระบบประเมินบุคลากร**
> ใช้คู่กับโค้ดเฉลยในโปรเจกต์นี้ ทุกโค้ดในคู่มือคัดลอกมาจากไฟล์จริง กดลิงก์เพื่อเปิดไฟล์เต็มได้

## คู่มือนี้ใช้อย่างไร

1. **อ่านทีละบท ตามลำดับ** แต่ละบทต่อยอดจากบทก่อน ห้ามข้าม
2. **แต่ละบทมี 2 ภาค:** ภาค ก = เข้าใจหลักการก่อน (ยังไม่เขียนโค้ด), ภาค ข = เขียนโค้ดทีละ **ขั้นเล็กๆ** (ครั้งละ 2-10 บรรทัด)
3. **พิมพ์โค้ดเอง อย่าคัดลอกวาง** การพิมพ์เองทำให้จำได้ และเจอ error ที่ต้องแก้เอง (วันแข่งไม่มีให้คัดลอก)
4. **อ่านตาราง 🔍 ทุกครั้งหลังพิมพ์** ให้รู้ว่าแต่ละบรรทัดทำอะไร และเอาไว้ใช้ทำอะไร
5. **ทำ "ลองเลย ✅" ให้ผ่านก่อนไปขั้นถัดไป** ถ้าไม่ผ่าน ดู "ปัญหาที่พบบ่อย ❗" ท้ายบท
6. ติดตรงไหน เปิดไฟล์เฉลยเทียบได้เสมอ (กดลิงก์ใน 📄 ท้ายหัวข้อ)

> 💡 **เวอร์ชันหน้าเว็บ:** เปิด `docs/guide/eva-guide.html` ได้แบบออฟไลน์ ทุกขั้นมีช่อง "ทำขั้นนี้แล้ว" ให้ติ๊ก และสารบัญด้านข้างแสดงว่าแต่ละบททำไปกี่ขั้นแล้ว

### สัญลักษณ์ในแต่ละขั้น
| สัญลักษณ์ | ความหมาย |
|---|---|
| 🎯 | ขั้นนี้จะได้อะไร |
| 📖 | อธิบายแนวคิดก่อนเขียนโค้ด |
| ⌨️ | พิมพ์โค้ด: บอกว่าสร้างไฟล์ไหน หรือพิมพ์ต่อตรงไหน |
| 🔍 | อ่านโค้ดทีละบรรทัด: บรรทัด / ทำอะไร / เอาไว้ใช้ทำอะไร |
| 🧩 | Syntax ใหม่: คำไหนเป็นคำสั่งของภาษา คำไหนตั้งชื่อเอง และต้องเรียงแบบไหน |
| ✅ | ลองเลย: ทดสอบว่าทำถูกแล้ว |
| ❗ | ปัญหาที่พบบ่อย และวิธีแก้ |
| 💡 | เกร็ดความรู้ / ทริค |
| 📄 | ไฟล์เต็มไว้เทียบ |
| 🏆 | ได้คะแนนเกณฑ์ข้อไหน |
| ⏱️ | เวลาที่ใช้: ครั้งแรกที่เรียน และวันแข่ง (เมื่อซ้อมจนคล่องแล้ว) |

### สีของคำในกล่อง 🧩 Syntax
| สี | ชนิดคำ | ตัวอย่าง |
|---|---|---|
| 🔵 น้ำเงิน | คำสั่งของภาษา (keyword) พิมพ์ตามนี้เป๊ะ | `const`, `async`, `return`, `SELECT` |
| 🟢 เขียว | ชื่อที่เราตั้งเอง เปลี่ยนได้ | `rows`, `topicRoutes`, `user` |
| 🟣 ม่วง | ชื่อของ package / ระบบ ต้องสะกดตามนี้ | `express`, `query`, `useState` |
| 🟠 ส้ม | ค่าข้อมูล | `"hr"`, `5000`, `true` |
| ⚪ เทา | เครื่องหมาย | `( )`, `{ }`, `=>`, `;` |

### โค้ดที่เขียนต่อกันหลายขั้น
ไฟล์ยาวจะเขียนทีละส่วน บรรทัดแบบนี้คือ **ที่ว่างให้ขั้นถัดไปมาพิมพ์แทน**

```js
// (ขั้น 3.8.2 จะเขียนต่อตรงนี้)
```

ใน JSX จะเป็น `{/* (ขั้น 8.3.4 จะเขียนต่อตรงนี้) */}` พอถึงขั้นนั้น ให้ **ลบบรรทัดนี้แล้วพิมพ์โค้ดใหม่ลงไปแทน**

## ภาพรวม: เรากำลังสร้างอะไร

ระบบประเมินบุคลากรของวิทยาลัย มีผู้ใช้ 3 กลุ่ม

```
┌──────────────────┐    ┌──────────────────────┐    ┌────────────────────┐
│  งานบุคลากร (hr) │    │ ผู้รับการประเมิน      │    │ กรรมการ             │
│                  │    │ (evaluatee = ครู)     │    │ (committee)        │
├──────────────────┤    ├──────────────────────┤    ├────────────────────┤
│ สร้างหัวข้อ       │    │ เปลี่ยนรหัสครั้งแรก    │    │ ดูคนที่ต้องประเมิน    │
│ สร้างตัวชี้วัด     │───▶│ ให้คะแนนตัวเอง        │───▶│ ดูหลักฐาน           │
│ เพิ่มผู้ใช้         │    │ แนบหลักฐาน PDF/URL    │    │ ให้คะแนน + ความเห็น  │
│ มอบหมายกรรมการ   │    │ ดูความก้าวหน้า         │    │ เซ็นชื่อ + ยืนยัน     │
│ ดูรายงาน/Dashboard│◀───│ ดูผล + Export PDF     │◀───│                    │
└──────────────────┘    └──────────────────────┘    └────────────────────┘
```

**ลำดับการใช้งานจริง:**
1. hr สร้างหัวข้อการประเมิน (เช่น "ด้านการสอน") กำหนดวันเปิด-ปิด
2. hr เพิ่มตัวชี้วัดในหัวข้อ (เช่น "ทำแผนการสอน" น้ำหนัก 20 คะแนน แบบสเกล 1-4)
3. hr เพิ่มผู้ใช้ (ครู, กรรมการ) ระบบสุ่มรหัสผ่านชั่วคราวให้
4. hr มอบหมายกรรมการให้ครูแต่ละคน (ประธาน 1 คน + กรรมการร่วม)
5. ครู login → ถูกบังคับเปลี่ยนรหัส → ให้คะแนนตัวเอง + แนบหลักฐาน
6. กรรมการ login → ดูหลักฐาน → ให้คะแนน → เขียนความเห็น → เซ็นชื่อ → ยืนยัน
7. ครูดูผล, hr ดูรายงานและ Dashboard

### สถาปัตยกรรม (ส่วนประกอบของระบบ)

```
  เบราว์เซอร์                     เซิร์ฟเวอร์                      ฐานข้อมูล
┌─────────────┐   HTTP + JSON   ┌──────────────┐   SQL    ┌─────────────┐
│  Frontend   │ ──────────────▶ │   Backend    │ ───────▶ │   MySQL 8   │
│  Next.js    │ ◀────────────── │   Express    │ ◀─────── │  (Docker)   │
│  port 3000  │  {status,       │  port 5000   │          │  port 3306  │
└─────────────┘   message,data} └──────────────┘          └─────────────┘
   หน้าจอที่ผู้ใช้เห็น              รับคำขอ ตรวจสิทธิ์             เก็บข้อมูล
                                 ตรวจข้อมูล คำนวณ
```

💡 **ทำไมแยก frontend กับ backend?**
- **frontend** ดูแลแค่ "หน้าตา" แสดงผลและรับข้อมูลจากผู้ใช้
- **backend** ดูแล "กฎ" ใครทำอะไรได้ ข้อมูลถูกต้องไหม และคุยกับฐานข้อมูล
- ถ้าวันหนึ่งทำแอปมือถือ ก็ใช้ backend ตัวเดิมได้เลย

## ก่อนเริ่ม: ความรู้พื้นฐานที่ควรมี

ไม่ต้องเก่ง แต่ควรรู้จักสิ่งเหล่านี้ (ถ้ายังไม่รู้ ครูควรสอนก่อน 1-2 คาบ):

- [ ] **HTML:** แท็ก `div`, `input`, `button`, `form`, `table`
- [ ] **JavaScript พื้นฐาน:**
  - ตัวแปร `const`/`let`
  - ฟังก์ชันลูกศร `() => {}`
  - array method: `map`, `filter`, `find`
  - object และ destructuring: `const { a, b } = obj`
  - template string: `` `สวัสดี ${name}` ``
- [ ] **async/await:** รู้ว่า `await` คือ "รอให้เสร็จก่อน"
- [ ] **SQL พื้นฐาน:** `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `WHERE`, `JOIN`
- [ ] **ใช้ Terminal:** `cd`, รันคำสั่ง `npm`

💡 **React ไม่ต้องรู้มาก่อน** บทที่ 07 จะสอนเท่าที่ต้องใช้ ระบบนี้ใช้ React แค่ไม่กี่อย่างซ้ำๆ ทั้งระบบ
